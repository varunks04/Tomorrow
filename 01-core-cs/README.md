# Domain 1: Core Computer Science Fundamentals

> **Cybersecurity Context:** Modern software vulnerabilities, malware mechanics, exploit development, and database leaks originate directly from computer science fundamentals. Operating systems govern kernel vs. user privileges; DBMS transactions prevent data inconsistency; OOP patterns structure secure code; and DSA efficiency prevents algorithmic Denial of Service (ReDoS / Hash DoS).

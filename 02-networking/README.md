# Domain 2: Networking Fundamentals

> **Cybersecurity Context:** The network is the primary attack vector for remote adversaries. Understanding packet encapsulation, transport protocols, subnet boundaries, DNS hierarchies, and TLS encryption is essential for diagnosing anomalies, configuring firewalls, and investigating security incidents.

# Domain 4: Identity & Access Management (IAM)

> **Cybersecurity Context:** Identity is the new security perimeter. In a cloud and hybrid enterprise, traditional network perimeters dissolve. Mastering modern auth protocols (OAuth 2.0, OIDC, SAML), token lifecycles (JWTs), and directory architectures (Active Directory, Kerberos) is indispensable.

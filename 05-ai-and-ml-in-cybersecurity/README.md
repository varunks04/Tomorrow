# Domain 5: AI & Machine Learning in Cybersecurity

> **Cybersecurity Context:** AI is dual-use in security: defensively, ML powers anomaly detection, UEBA, automated triage, and malware classification. Offensively, attackers use AI for phishing and evasion, while AI applications themselves introduce novel attack surfaces like prompt injection and data poisoning.

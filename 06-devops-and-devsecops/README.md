# Domain 6: DevOps, Cloud Computing & DevSecOps

> **Cybersecurity Context:** Modern breaches frequently originate from misconfigured S3 buckets, exposed API tokens in Git, unpatched container base images, and compromised CI/CD runners. Shifting security left into pipelines and enforcing cloud IAM boundaries is critical.
